◐

Add it, don't scrape it

Drop in a TikTok URL and EthnoFlow reads only the platform's public oEmbed preview — no scraping, no login. Jot a field note or import a file instead, and it becomes a codeable artifact right alongside your captures, in the same corpus.

⟐

Three-panel workspace

Provenance and ethics on the left, the record — caption, transcript, on-screen text — in the middle, analysis on the right. Nothing about where a piece of data came from or what you're allowed to do with it is ever more than a glance away.

✎

Code the irony, not just the words

Select any passage and apply a code. A first-class ironic / sarcastic modifier lets you mark post-irony by hand — the register a sentiment model reliably gets wrong, and TikTok runs on.

◫

A codebook that doesn't lie to you

Codes carry real operational definitions — definition, inclusion, exclusion, anchor — to keep interpretation stable across sessions. Redefine, merge, split, or deprecate one and EthnoFlow versions it, previews the impact, and flags segments coded under the old meaning as drifted for your review. Never silently rewritten.

◈

Ethics built in, not bolted on

Every artifact carries its own anonymization tier and safety flags — possible minors, identifiable place, sensitive topic — from the moment it's captured. Memos and an append-only journal keep an audit trail of captures and codebook changes alongside your analytic thinking.

✦

Export & interoperate

A FieldScribe backup (plain or encrypted) that opens natively in FieldScribe Desktop, a portable encrypted SQLite project file, a Markdown vault for Obsidian, or CSV tables for quantitative work. Four formats, all generated locally, all yours.

The same rhythm as any other fieldwork — document first, make sense of it after — just built around a platform instead of a place.

  1. 01 Add a TikTok by URL, jot a field note, or import a file — all become codeable artifacts in one corpus.
  2. 02 Build a codebook with operational definitions, and code passages — including the irony a sentiment model would miss.
  3. 03 Redefine, merge, split, or deprecate codes as your thinking evolves; segments coded under an old meaning are flagged as drifted for review, never silently rewritten.
  4. 04 Export to a FieldScribe backup, an encrypted project file, a Markdown vault, or CSV — all generated locally, all yours to keep.

Why not just screenshot and paste into NVivo?

That's the default workflow for a lot of platform ethnography right now — and it's the one EthnoFlow is built to replace, not the mature CAQDAS suite at the end of it.

How to Install

These builds aren't code-signed — that's normal for desktop software distributed outside an app store. Here's how to get past the first-launch warning on each platform.

macOS

One-time step per install.

  1. Open the .dmg and drag EthnoFlow into Applications
  2. Double-click to open. macOS will often refuse outright, especially on Apple Silicon:
    "EthnoFlow" is damaged and can't be opened. You should move it to the Bin.
    It isn't damaged — don't delete it. This is Gatekeeper rejecting an app with no paid Apple Developer signature, and the usual "Open Anyway" setting won't even appear for this one.
  3. Open Terminal (⌘Space → type Terminal) and run:
    xattr -cr /Applications/EthnoFlow.app
    This clears the quarantine flag that triggers the check — it doesn't touch the app itself.
  4. Open EthnoFlow again — it launches normally from here on

Some Macs show the milder "unidentified developer" prompt instead — if so, just use System Settings → Privacy & Security → Open Anyway, no Terminal needed.

Windows

SmartScreen flags unsigned installers by default.

  1. Run the .exe (or .msi) installer
  2. Windows Defender SmartScreen will show:
    Windows protected your PC.
  3. Click More info, then Run anyway
  4. Follow the installer as normal

Linux

Pick whichever matches your distro.

  1. AppImage: chmod +x the file, then run it directly — no install step
  2. .deb: sudo dpkg -i the file on Debian/Ubuntu-based distros

Why the warnings — and why macOS sometimes says "damaged"? EthnoFlow isn't code-signed with an Apple Developer certificate or a Windows signing certificate — both cost money per year, well beyond what a free research tool asks of you. On macOS specifically, an app with no paid signature that's been downloaded from the internet can trip Gatekeeper's strictest check, which reports it as "damaged" rather than showing the friendlier "unidentified developer" prompt — the app isn't actually damaged, and the Terminal command above resolves it. Network calls are off by default, and you only need to clear the warning once per install.

About the Developer

EthnoFlow is built and maintained by Ulysses S. Cabayao, whose path into anthropology began with a Master of Anthropology (Advanced) from the Australian National University. He is now a PhD candidate at University College London, where his research examines sovereignty, frontiers, and settler-colonialism in the United States. He also builds research software and explores how AI can support qualitative fieldwork — projects across the ainsight ecosystem, including FieldScribe for field notes and qualitative analysis, Sacrosanctum for parish life, Vantage for university leadership, HouseOps for property maintenance, and NLIST for board exam enrollment — all sharing the conviction that good tools shouldn't be gated behind an enterprise budget. EthnoFlow grew out of that same frustration.
